1) One Codebase, Many Interfaces: Practical API Design with REST, GraphQL, SDKs, and CLIs

Master the art of building scalable, multi-interface APIs with a single TypeScript monorepo, using modern practices like TurboRepo and Nx workflows.

What You'll Learn:

  • Design APIs using shared logic across REST, GraphQL, SDKs, and CLIs
  • Learn real-world validation, auth, and error-handling best practices
  • Discover the Adapter Pattern to build modular systems

Why It Matters:

In today's fast-paced world, modern apps need flexible, reusable systems. This workshop will teach you to design high-performing systems that real-world teams rely on.

Outcome:

You'll gain the skills to build and deploy scalable, multi-interface APIs—making you an indispensable asset to any team.

2) Build & Deploy Your Own Design System: Atomic Design, React, Storybook, Tailwind

Create a scalable and reusable design system using React, Tailwind CSS, and Storybook, powered by Atomic Design principles.

What You'll Learn:

  • Atomic Design principles to create UI components
  • Tailwind-based theming and ensuring accessibility
  • Storybook-driven documentation and testing for UI components

Why It Matters:

Design systems are the backbone of consistency in modern UI development. This workshop will give you the tools to design systems that improve team productivity and ensure UI consistency.

Outcome:

Leave with a production-ready design system that you can deploy and scale across multiple real-world projects.

3) No NPM, No Problem: Build a Full Web App with Just Node.js Core

Dive deep into the core of Node.js and build a complete web app using only Node.js core modules—no npm, no frameworks.

What You'll Learn:

  • Core Node.js modules like http, fs, url, and crypto
  • Manual routing, templating, and data handling
  • Build your own router, template engine, and file handler

Why It Matters:

By learning to build with raw Node.js, you'll gain a deep understanding of how backend systems work, allowing you to create faster, leaner, and more portable systems.

Outcome:

You'll gain confidence in backend development, creating a full-fledged app from scratch with nothing but core modules.

  • PostgreSQL internals: indexing, partitioning, and performance tuning
  • Real-world database lifecycle management

Why It Matters:

PostgreSQL is used by some of the biggest tech companies. This workshop will equip you with the skills to design robust, scalable databases that perform under pressure.

Outcome:

By the end, you'll have the expertise to build and scale PostgreSQL databases that power high-performance applications.
